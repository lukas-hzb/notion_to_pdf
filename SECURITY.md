# Security policy

## Supported versions

Notion to PDF is currently an alpha project. Security fixes are applied to the
latest revision on the default branch; older revisions are not maintained.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the repository owner privately through the
contact method on the [GitHub profile](https://github.com/lukas-hzb).

Include the affected revision, platform, reproduction steps, expected impact,
and whether private Notion data could be exposed. Do not include real exports,
credentials, tokens, or personal documents in the initial report.

Please allow a reasonable period for investigation before public disclosure.
There is currently no bug-bounty program.
