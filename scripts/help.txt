Notion to PDF — local HTML export converter (alpha)

Usage:
  notion-to-pdf --input <ZIP/HTML/folder> --out <directory> [options]
  npm run export -- --input <ZIP/HTML/folder> --out <directory> [options]

Layout:
  --preset original|reading|print    Default: original
  --paper A4|Letter                  Default: A4
  --landscape                        Use landscape orientation
  --margin <mm>                      8–35 mm; default: 16
  --font-size <pt>                   9–16 pt; default: 11
  --columns preserve|stack           Keep source widths or stack columns
  --tables split|wrap                Repeat title column (or first) in wide tables
  --bookmarks card|compact           Bounded preview cards, or title and URL only
  --toggles expanded|sections        Open toggles or ordinary sections
  --tasks checkboxes|bullets         Static checkboxes or ordinary unstruck bullets
  --no-task-status                   Deliberately remove completion state
  --keep-task-status                 Retain completion styling even in bullet mode
  --no-page-numbers                  Hide page numbers
  --continuous                       Render each document as one long page without a footer
  --no-cover                         Omit the page cover

Selection and checks:
  --database-pages all|content       All records, or only records with body content
  --list                            List zero-based page indices; no --out needed
  --page-index <n>                   Export one page; repeat to select several
  --inspect-only                    Save import report without creating PDFs
  --doctor                          Check Node, build and print-runtime installation
  --strict                          Stop on known import/layout warnings
  --help, -h                        Show this help
  --version                         Show version

Each export creates a new Notion-PDF-* folder with separate PDFs and an
export-report.json. Original files are never modified. Progress goes to
stderr; the final JSON summary goes to stdout. External content images stay
offline and produce warnings; bookmark previews are omitted with an info entry,
preserving their text and links. Reading/print skip property-only records and
list them in the report. Override with --database-pages all. The original
profile includes all records and their properties. Reading/print preserve columns
and use ordinary bullets without completion styling. Use
--keep-task-status to retain it. Existing database tables remain unchanged by
page filtering. Explicit strikethrough formatting in source text is preserved.
Help, version, doctor, --list and --inspect-only do not start Electron.
PDF conversion still needs Electron as its isolated Chromium print engine.
Bookmark cards preserve local thumbnails/icons and show a short description preview.
--bookmarks compact deliberately omits description and decoration; captions stay.
